# LICENSES/ACD-1.4-CLARITY-TRIAL.md

## What

1.4 草案の **B3 / B13（法的な明瞭さと解釈の負荷）** について、許諾の範囲・権利主体・法的効果を保ったまま、
言い直しの族と読みの分岐を減らせるかを試す作業ファイル。候補・試作・効果の対照・反例テスト・KPI を 1 か所に置く。

## Why

OSI の新規ライセンスの承認基準のうち、曖昧さ（基準 3）と明晰さ（基準 4）に直接当たるから。語数の削減は
2026-09-09 に「縮められるが答えきれない」と結論済みで、今回は語数ではなく、同じ主張を複数の条で言い直す形と、
理由の文が自分で作る反対解釈の分岐を対象にする。

## How

草案を直接上書きしない。候補（bb）→ 試作と効果の対照（25）→ 効果を運ぶ語の差分（5a の道具）→ 反例テスト（bb）
の順に書き足し、**反例が出ず効果の保存を条ごとに説明できたものだけ**を草案と `ACD-1.4-CHANGELIST.md` へ反映する。

## Constraints

- 凍結版（1.0〜1.3）には触れない。法的効果を変える案は新規版候補として扱い、ここでは採らない。
- 語数の削減・CI の成功・文書の追加を、承認の見込みが上がったことと扱わない。

## Change impact

採用した変更は草案と CHANGELIST に記録し、この file には試作と反例の経過を残す。

## Audience-specific notes

- **AI（次のセッション）**: 候補の「経緯」の列（どの errata を閉じるために足された文か）が反例の第一の材料。
- **監査人**: 構造表は道具で導出した機械的な分類で、型の列は目安である。
