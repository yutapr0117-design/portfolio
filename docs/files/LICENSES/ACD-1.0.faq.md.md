# LICENSES/ACD-1.0.faq.md

## What

**レビュアではなく「実際に使うかもしれない人」の疑問**に答える FAQ。3 部構成。

- **A. 使う側**（12 問）: 適用の仕方 / 帰属表示 / 改変再配布 / 用途制限 / GPL・Apache との組み合わせ（**逆向きは別の話**）/ 特許を持っている場合 / データ・モデル / 学習と出力 / 作者の死亡・破産 / **SPDX 未登録時の表記** / **依存スキャナが未知と言う場合** / 法務への説明材料
- **B. プロセス**（5 問）: 現在の段階 / 却下や無反応 / SPDX の時期 / 1.1 の作り方 / 連絡先
- **C. リポジトリのどこを見れば何が分かるか**（逆引き 11 行）

## Why

想定問答・逐条・族比較・法域はいずれも**審査を受ける側の視点**で書かれている。だが「疑問が全てリポジトリを見たら潰せるように」という目標には、**使う側の実務**が要る。

とくに次の 2 問は、他のどの文書にも答えが無かった。

1. **SPDX 識別子が無い状態でツールにどう書くか** ―― 未登録なので `LicenseRef-ACD-1.0` として全文を添えるのが標準的な扱いになる。§16.1 の通知が `SPDX-License-Identifier: ACD-1.0` を含むのは**登録の主張ではなく通知の様式**（§16.2）だという説明も要る。
2. **依存関係スキャナが「未知のライセンス」と言う** ―― 想定内である。手動登録 / ポリシー上の分類へマップ / **判断できないなら使わない**（これは正当な選択であり、こちらから止める理由は無い）。

## How

- 各問に「そのまま貼れる英文」＋日本語の補足。
- **A12（法務への説明材料）は表で場所を示し、最後に「弱点の場所を先に示すこと」と書いた** ―― 法務が自分で見つけると、その後の説明が全部疑われるため。
- **C の逆引き表**が「疑問 → 見る場所」の入口。**ここに無い疑問が出たら、それはこの一覧の欠落である**と明記した。

うち 3 件を追加した。

| 追加 | なぜ genuine か |
|---|---|
| **A13 既存プロジェクトからの移行** | 採用者の最頻質問。**「自分が全ての権利を持っているか」で答えが変わる**。過去の頒布には及ばないこと・**適用は不可逆**（§2.2 / §2.5）であることを明示 |
| **A14 輸出規制・制裁法** | 法務の定番チェック。**「無条件」は「法的義務が消える」という意味ではない** ―― §2.7 / §11.4 / §13.2 が一貫して「Dedicator が持っているものしか渡せない」と述べている |
| **A15 公共調達で「OSI 承認済み」が要件** | **その場合は使えない**と書いた。承認されていないものを「実質的に同等」と言わせるのは、こちらの都合で相手の信用を使わせることになる |

**「税務・会計」は追加していない** ―― ライセンスが扱う対象ではなく、書けば padding になる。

**この走査方法は再実行できる。** 語彙を足して走らせれば、次の欠落が出る。

### 2 巡目（同日・語彙 24 項目）

7 件が未扱いで、**うち 5 件を追加、1 件を意図的に落とし、1 件は投機的として見送った**。

| 追加先 | 内容 |
|---|---|
| FAQ **A16 SBOM** | 未登録識別子は `LicenseRef-` で記録し全文を添える。**「似ているから」で CC0 等に丸めない** ―― CC0 は特許を明示的に除外しており、丸めると SBOM が**実態と逆のことを記録する** |
| FAQ **A17 fork / vendoring / ミラー** | 必要な行為はゼロ。ただし §4.6 —— 付けた条件は自分が与えるものを規律するだけ |
| FAQ **A18 名称・識別子の商標** | **登録していない**。識別子を守るのは商標法ではなく **§16.4**。商標は登録・維持・行使のコストを steward に課し、**§13.3（保守義務を負わない）と整合しない** |
| FAQ **A19 廃止できるか** | 適用済みの作品については**できない**（§2.2 / §2.5）。廃止は「新規に薦めない」までしか意味しない |
| comparison **§5.5 CC0 + 特許誓約** | **最も鋭い代替案**。差は優劣ではなく**構造** ―― (1) 二文書に分かれ下流に届かない (2) 誓約の条件は別文書が決める (3) **モデルと出力に届かない**（§8.4 の存在理由）。「届く誓約を示されたらそれを使う」とも書いた |

**見送り**: C2PA / 電子透かし（投機的）、税務・会計（ライセンスの対象外）。
