# LICENSES/ACD-1.0.dig-2026-09.md

## What

**2026-09-17 に `license-discuss` の 93 か月分を取得して行った掘削と、そこで検定した仮説の記録。**
扱うのは「**なぜ我々の投稿に返信が無いのか**」で、**長さ・新参・個人であること・問いの重さ**を
それぞれ当てた結果が入っている。

## Why

**測れる問いに散文で答えない** ——`REVIEWERS.md` が掲げる *check us* がそれを要求する。
沈黙の理由は仮説が立てやすく、**立てたまま検定しないと、次の判断がその仮説の上に乗る。**
実際、**「8 月の投稿は長すぎた」は我々の測り方の誤りだった**（添付をアーカイブが展開したものを
本文として数えていた）——**その誤りは、短い版を送るという判断の根拠になっていた。**

## How

- アーカイブを月次 `.txt` で取得 → **encoded-word を復号してから**件名でスレッド化
- **事務連絡（月次ダイジェスト）を除外**する（しないと返信ゼロのダイジェストが長文バケットを汚染する）
- 返信は**開始者以外**の投稿のみ数える
- **clean も否定も同じ重さで書く** —— 4 仮説のうち 2 つは否定された

## Constraints

- **`rounds/` の一次資料は無改変**。ここに置くのは測定と読みであって、受領文ではない
- 節番号は `§1.xx` の**共有系列**で、Check 471(f) が file をまたいだ重複を禁じる
- Check 459 が索引（`LICENSES/README.md`）からの到達性を、Check 461c が `last-updated` を強制

## Change impact

**新しい掘削を足すときは、まず「census か検定か」を決める** ——
件数を数えるなら `review-corpus.md`、なぜそうなったかを当てるならここ。

## Audience-specific notes

- **審査者**: 我々自身の沈黙について、**説明が付かないという結果**まで含めて公開している面である
- **後任 AI**: **仮説を採る前にこの file を読む。** 長さ・新参・個人・問いの重さは**当て済み**で、
  そのうち 2 つは否定されている。**同じ仮説を再発明しないこと。**
