# LICENSES/ACD-1.0.review-readings.md

## What

未読のスレッドと審査の帰結を読んだ記録のうち、§1.164 以降の節。`reviewer-positions.md` と `gap-measurements.md` が予算に近づいたので、2026-11-09 から新しい節をここに置く。

## Why

決める側と審査に近い人の発言を、ACD への当たり方と逆側をつけて残し、提出文と register が引けるようにする。

## How

各節は原文の引用・発言者・日付・ACD への当たり方・逆側・「この節が establish しないこと」を持つ。原文は `rounds/` に置く。§1.xx は `ACD-1.0.*.md` の共有の採番で、Check 471 (f) が衝突を見る。

## Constraints

既存の節を動かさない（他の文書の `§1.1xx` の参照を壊さないため）。引用は逐語で、`verify_dossier_quotations.py` が原文に当てる。

## Change impact

`ACD-1.0.against.md`・`ACD-OSI-BOTTLENECKS.md`・`REVIEWERS.md` がこの文書の節を引くことがある。

## Audience-specific notes

- **審査者**: ここは読みの記録で、提出文ではない。
- **監査人**: 各節の `rounds/` の file で原文を確かめられる。
