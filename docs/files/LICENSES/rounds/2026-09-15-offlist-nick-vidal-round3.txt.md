## Why

**この往復が、我々の発信が止まっている理由そのものだからである**（`FROZEN.md` の
`POSTING-STATUS` / `REVISION-PROTOCOL.md` ゲート 0 / register の B14）。

**2026-09-15 の要求は 3 つ。** (1) Code of Conduct の *"Respect time and attention"* との整合、
(2) **メールの長さと密度を、他の人間の投稿と比べて示すこと**、
(3) 公開通知の一文 —— *"We do not allow posts generated by AI without careful review from the
author **and will reject posts where we suspect that an AI has been responsible for all or most of
a message**"* —— を理解しているか、**現在のワークフローがこれを満たすか、満たすならどう満たすか**。

**(2) は測れる問いなので測った**（`review-corpus.md` §1.85 / `measure_list_verbosity.py`）。
**(3) は測れない** —— 条文の読みと、ワークフローをどうするかの決定である。
**どちらも steward の判断であり、本リポジトリは材料までを用意する。**

## How

**steward が貼った内容を、そのまま 1 本のテキストにして保存した。** 各メールの前に
**差出人・日時（JST）**の区切りを置き、本文は改行位置を含めて手を入れていない。
2026-09-07 の 5 問への回答だけは**別 file に既に在る**ので、本 file ではその旨を指してある
（**同じ文を 2 箇所に置くと、片方だけが直されたときに食い違う**）。

添付 PDF は**送られた事実だけ**を冒頭に記し、中身は再現しない。

  「送られていない」を意味しない**し、逆に**ここに在ることは公開されたことを意味しない**。
- **⚠ この往復の内容を、リスト上で論じない**（`REVISION-PROTOCOL.md` ゲート 0）。私信である。
- **⚠ この file を根拠に「OSI の立場」を述べない。** moderator の行為は組織の決定ではない
  （B14 に同じ注意が書いてある）。
