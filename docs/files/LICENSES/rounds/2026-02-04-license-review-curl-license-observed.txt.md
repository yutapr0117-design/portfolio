## What

**我々宛ではなく、ACD-1.0 についてでもない。**

**同じスレッドのもう一方のリスト側は別 file に在る** —— `rounds/README.md` の命名規約が
venue を file 名に持つためで、**2 つのリストを 1 file に混ぜるのは規約違反である**
（**⚠ 2026-09-24 に一度そうしてしまい、Check 365 の 1,000 行上限に当たって気づいた**）。

## Why

**B1 / B2 の二経路が、原理ではなく*投票の言葉*で現れた唯一の例だから**（`against.md` #220）。

**同じテキストが、新規としては却下され legacy としては承認されうる。動かすのは採用であって
起草ではない。** **ACD-1.0 の採用は 1 件なので、その経路は我々に閉じている。**

**⚠ 逆向きに効く事実も同じスレッドに在る** —— **四票が 1 日で付いたのに 3 か月動かなかった。
全会一致の支持は決定ではなく、遅れは不承認ではない。**

## How

ブラウザ相当の UA で取得した既存キャッシュから、該当メッセージを無改変で切り出した。
**見つけ方は、決める側 4 人が 2026 年に発言した 47 スレッドの列挙。**

- **観測（`-observed`）であって受領ではない。**

- **有利な半分だけを引かない。**
