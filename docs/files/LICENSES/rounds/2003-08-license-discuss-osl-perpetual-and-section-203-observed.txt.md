# LICENSES/rounds/2003-08-license-discuss-osl-perpetual-and-section-203-observed.txt

## What

"Open Source Licensing"（`license-discuss` 2003-08・3 通）の全 3 通を無改変で置いた。Lawrence E. Rosen 氏が、OSL の *perpetual* は当事者が本当に永遠を意図するならそう書いてよく、35 年の終了権（17 U.S.C. §203）は職務著作には及ばないと書いた通と、Mahesh T. Pai 氏、Ian Lance Taylor 氏の返信。

## Why

ACD の §4.1・§8.1 の *perpetual* と §203 の関係について、`ACD-1.0.jurisdictions.md` §5c の 2007 年の追記（本当に perpetual なライセンスは無い）の逆側として置く。
