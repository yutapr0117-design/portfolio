# LICENSES/rounds/2026-11-16-fsf-license-list-and-debian-dfsg-public-domain-snapshot.txt

## What

FSF の license-list の CC0・Unlicense・公有・0BSD（#Zero-BSD）・Expat0 の 5 項と、Debian Wiki の DFSGLicenses の公有の段を、2026-11-16 に WebFetch で取得した結果（0BSD と Expat0 は同じ日に portfolio-30 の依頼で足した）。バイト単位の写しではなく、道具が返した 120 字以内の逐語の片の並び。

## Why

`ACD-1.0.review-readings-2.md` §1.229 が出典無しに書いて取り下げた「FSF と Debian は CC0 をソフトウェアに勧めない」と、§1.253 の手がかり（CC の側の 2011 年の報告）を、FSF と Debian 自身の文で確かめるため。オーナーが 2026-11-16 に gnu.org の取得を許可した。

## How

WebFetch で取得した（curl での生の取得は自動の判定で止められ、取り直しは 429 で止まった）。先頭に取得の方法と限界を書き、以下に道具の返した片を番号つきで置いた。

## Constraints

写しは道具を通ったもので、片と片の間に語が無いとは保証しない。引く前に取り直して比べる。FSF も Debian も ACD を評価していない。

## Change impact

この写しを引く節（§1.229・§1.253）と register（B10・FSF と Debian の自己点検）を直すときは、ここの番号の片が本当に在るかを取り直して確かめる。
