# LICENSES/rounds/2026-11-16-minpo-chosakukenho-e-gov-api-snapshot.txt

## What

日本の民法 527 条・549 条・550 条と著作権法 59 条・60 条・63 条（1〜4 項）・63 条の 2 の条文を、2026-11-16 に e-Gov 法令 API から WebFetch で取得した結果。バイト単位の写しではなく、道具が返した逐語の片の並び。

## Why

1.4 草案の §2.3・§2.2・§8.2・§2.8・§12.2・§12.4 を、日本の条文に当てるため（jurisdictions §2）。

## How

WebFetch で取得し、先頭に取得の方法と限界を書いた。

## Constraints

写しは道具を通ったもので、片と片の間に語が無いとは保証しない。条文であって ACD への判断ではない。当て方の読みは jurisdictions §2 に在り、法律家の確認は無い。

## Change impact

`ACD-1.0.jurisdictions.md` の日本の節がこの写しを引く。直すときは写しを取り直して比べる。
