# LICENSES/ACD-1.0.review-doctrine.md

## What

`license-review` / `license-discuss` で論じられた法理を、**ACD-1.0 の特定の条へ当てた**読み。
§1.84（委員長の原理を §6.3 に当てる）/ §1.100（OSD 5 の広い読みと §10.4）/
§1.101（学習のための複製と TDM 例外）/ §1.109（§8 の特許・§5 の covenant）。

## Why

**`ACD-1.0.review-precedents.md` が 955 行で advisory (900) を越えたので切り出した。**
**割る線は行数ではなく主題で選んだ** —— 残した側は「**他の提出に何が起きたか**」の記録
（撤回・却下・承認・改名・理事会の議決）で、本書は「**その法理を我々の条に当てるとどうなるか**」。
**読み手の用途が違う**（前者は「我々はどう扱われるか」、本書は「この条は何を言われるか」）。

## How

**節番号は変えていない**ので `§1.84` 等の参照は番号としてそのまま解決する。
**file 名を添えていた参照（4 件）は同じ commit で本 file へ向け直した。**

## Constraints

- **「顛末」と「法理」は排他ではない。** §1.57（Unlicense への veto）のように、顛末でありながら
  その論拠が ACD の条文になっている節もある。**境界は読み手の用途で引いてあり、論理的な分類ではない。**
- 逐語引用の出典は `rounds/` の無改変保存。**ここで引用を書き換えない。**

## Change impact

節を足すときの行き先は「**他人に何が起きたかの記録か / 我々の条に当てられた法理か**」で決める。
迷ったら `review-precedents.md` へ置き、本書からは番号で参照する。

## Audience-specific notes

- **監査人**: 各節は逐語引用と出典（`rounds/` の file 名）を持つ。引用の忠実性は Check 472b が照合する。
- **第三者**: **ここに在るのは他人の議論の読みであって、ACD-1.0 への応答ではない。**
