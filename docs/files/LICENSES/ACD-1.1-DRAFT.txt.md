# LICENSES/ACD-1.1-DRAFT.txt

## What

**次版 ACD-1.1 の草案。** 冒頭に **NOT IN FORCE / NOT SUBMITTED / NOT APPLIED** と自分で述べる。
**このリポジトリを覆っているのは 1.0** であり、その本文は凍結され sha256 が pin されている。

第 1 段（machinery のみ）で入れた変更: §2.2 が 1.0 の §15.5 を吸収 / §2.5 圧縮 /
§2.9 は事実を残し *"not executory"* の結論を落とす（E5）/ 1.0 の §15.2・§15.3・§15.5・§15.6 を削除し
§15.4・§15.7・§15.8 を §15.2・§15.3・§15.4 へ繰り上げ / §16.4 が翻訳の但し書き（1.0 の §16.5）を
吸収し、**識別子の保護を `ACD-1.0` 単体から `ACD-N` / `ACD-N.N` の族へ広げる**（E14）。

**その後 4 段を重ねた（同日）**: **E3 + E12**（§16.1 の notice が両端で言い過ぎていた）/
**E16**（§2.6 の痕跡の残らない opt-out を、**Dedicator の自己拘束**で可視化）/
**E13**（§1 の並べ替え。**前方参照 3 → 2** ——**相互定義は 2 対あり、E13 の「1 件」は誤りだった**）/
**E15**（§8.4 に**因果の限定**。量の閾値は条件になるので採らない）。

**1.0: 4,896 語・82 条 → 本草案: 4,742 語・77 条（正味 −154 語）。**
**機構部 −302 に対し、正確さのために +148** ——**長さは正確さと直接競合する**（register B3）。

## Why

**オーナーが 2026-09-10 に「現行ライセンスはそのまま保持する必要があるが、次版を作成して
改善し続けるのは問題ない」と述べた。** これは `REVISION-PROTOCOL.md` §2（**1.0 は永久凍結・
次版は併置**）が最初から定めていた形であり、**設計だけで止めていたものを実物にした。**

## How

- **1.0 を機械的に変換して作った**（節の削除・繰り上げ・吸収）。**手で写していない。**
- **繰り上げ後に相互参照を実際に確かめた** —— §12.6 の「可分性が適用される」参照は
  1.0 の §15.4 を指していたので **新 §15.2 へ付け替えた**。
  **⚠ ここで「dangling が 0 件だから安全」と読みかけた** —— 旧 §15.4 への参照は
  **新 §15.4（言語）へ解決してしまう**ので、**検出器は黙って通す。番号ではなく意味で確かめること。**
- 検算: **非 ASCII 0 バイト / 16 節連番 / 定義語 10 件すべて使用（最少 3 回）/ `ACD-1.0` の残留 0 件**

## Constraints

- **1.0 には触らない。** Check 453 が 3 ファイルの sha256 を pin している
- **この草案を「適用」しない。** `LICENSE` は 1.0 を指したままであり、変える理由は無い
- **草案の条番号を 1.0 の引用に使わない**（§15 以降がずれている）
- **変更は必ず `ACD-1.1-CHANGELIST.md` に記録してから入れる** ——**記録の無い変更を入れない**

## Change impact

**残るのは E11 のみ**（steward が自ら list に出した問いで、**外部の回答待ちなので触らない**）。
**Check 468 が本ファイルを守る** ——身分表明（NOT IN FORCE / NOT SUBMITTED / NOT APPLIED）/
純 ASCII / `Section N.M` の解決 / **冒頭が申告する語数・条数が実測と一致すること**。
