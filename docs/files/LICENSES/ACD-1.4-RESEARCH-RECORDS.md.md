# LICENSES/ACD-1.4-RESEARCH-RECORDS.md

## What

1.4 の作業で外部資料を当てた記録。2026-10-28 に、オーナーが渡した外部資料 5 本、OSAID 1.0 の原文と日本語参考訳、OSAID 1.0 への照合、opensource.org の全ページの読み直しを 1.4 草案に当てた結果の 4 節を持つ。

## Why

もとは `ACD-1.4-CHANGELIST.md` の節だったが、その file がバイトの予算の advisory（200,000）を超えたので、どの Check も読んでいない調査記録の節を移した（2026-11-12）。変更の記録（主表・語数の内訳・記述子の下書き・切り替えの日の表）は CHANGELIST に残る。

## How

節は無改変で移した。節の中の「上の表」「下の表」は CHANGELIST の主表を指す。

## Constraints

- 本文を書き換えない。新しい調査の記録はここへ足さず、その時点の正規の記録先へ書く。
- errata の状態（E-ID と状態の語）はここに書かない。Check 469(b) は `ACD-*-CHANGELIST.md` だけを読むので、ここに書くと照合から落ちる（portfolio-9b・2026-11-12）。

## Change impact

- 節を参照する文書（`SUBMISSION-MATERIALS.md` の OSAID の行など）は、この file を指す。

## Audience-specific notes

- **ai**: OSAID との照合の結論を探すときはここを読む。
- **human (新卒)**: 1.4 草案に外から何を当てたかの記録で、変更そのものは CHANGELIST にある。
- **監査人**: 2026-10-28 の時点の取得と読みで、それ以後の改定は反映していない。
- **第三者全般**: 読みの記録であって、法律家や OSI の判断ではない。
