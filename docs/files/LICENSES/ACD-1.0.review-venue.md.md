# LICENSES/ACD-1.0.review-venue.md

## What

**審査の場（`license-discuss` / `license-review`）がどう働き、誰がそこで書いているか**の記録。
pre-review としての `license-discuss`・沈黙の比較・書き手の記録・steward 自身の分析・
moderator が引いた CoC 条項（§1.67 / §1.68 / §1.69 / §1.92 / §1.99 / §1.106 / §1.107）。

## Why

`ACD-1.0.reviewer-positions.md` が 998 行で Check 365 の 1,000 行上限まで 2 行だったので、
**上限に当たる前に**テーマで分けた。元の file には「主題ごとの審査者の立場」が残る。

## How

節番号は共有採番（`§1.xx`）のまま動かしていない。ファイル名つきの参照は付け替え、
裸の参照は Check 471 (e) が `ACD-1.0.*.md` から導出した系列で解決する。

## Constraints

- **節番号を動かさない**（他文書は番号で参照する）。
- 新しい節を足すときは、共有採番が衝突しないことを Check 471 (f) が見る。

## Change impact

この file の節を別の file へ移すときは、ファイル名つきの参照を同じ commit で付け替える。

  「場がどう働くか」はここ。
