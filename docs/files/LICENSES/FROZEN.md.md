# LICENSES/FROZEN.md

## What

**ACD-1.0 が凍結中であること**を、ファイルの存在で表すマーカー。オーナーが SPDX / OSI へ申請
するため「結果を伝えるまでライセンスをそのままにしておいてほしい」と述べた（2026-08-24）。

凍結対象 3 件の **sha256 を pin** しており、**Check 453** が BLOCKING で照合する。

## Why

**「触らない」を記憶や善意に委ねない。** このリポジトリは AI が無限に自走して改善を続ける
前提で動いており、**次のセッションの担当（人でも AI でも）はその会話を見ていない**。
凍結を git 上の成果物にして BLOCKING Check で縛れば、うっかり触った時点で CI が赤くなって止まる。

審査中にテキストが動くと、**審査側が見ているものと公開されているものが食い違う**。SPDX は
テキスト一致で照合し、識別子とテキストは 1 対 1 で対応しなければならない（条文自身も §16.4 で
そう定めている）。

## How

`FREEZE-DATA` ブロックが `<sha256>  <path>` の 1 行 1 ファイル形式で、Check 453 の単一ソース。
Check は (1) 各ファイルの実 sha256 との一致、(2) **対象 path の集合**が変わっていないことの
2 面を見る。後者があるのは、**対象を表から外せば Check は黙る**からで、それは実質的な凍結解除
にあたる。

## Constraints

- **Check 453**（BLOCKING）: 凍結対象が申請時点のままであること
- **sha256 を書き換えて Check を黙らせない。** 本文に是正すべき欠陥を見つけた場合でも、
  直すのではなく**オーナーへ報告する**
- 存在＝凍結。**解除はファイルの削除で表す**（オーナーが結果を伝えたときのみ）

## Change impact

- オーナーが結果を伝えた → 結果を `acd-license-rationale.md` へ記録し、本ファイルを削除
- 承認された → `ACD-1.0` が指すテキストは恒久的に不変（§16.4）。改善は `ACD-1.1` 以降で
- 差し戻された → 指摘に基づく改訂は**別バージョン**として出す（同じ識別子で差し替えない）

## Audience-specific notes

### For AI agents

- **凍結中でも、ライセンス以外の改善は通常どおり自走してよい。** 止まるのはライセンスだけ。
- 本文に欠陥を見つけたら、**直さずに報告する**。審査中の差し替えは乖離を生む。
- Check 453 が赤いときは「直し方が分からない」ではなく「**触ってはいけないものを触った**」の
  合図。`git checkout -- LICENSES/` で戻すのが正しい。

### For 監査人

- 3 通りの破り方（本文の 1 語変更 / 末尾に空白 1 文字 / 対象を表から外す）で RED を実測済。
- 凍結の根拠となったオーナーの発話を本文に原文で引用してある。
