# LICENSES/ADOPTING.md

## What

**ACD を自分の著作物へ適用しようとする人向けの英語の 1 枚（2026-11-06 作成）。** 取り消せないこと、分かっていないこと、別のライセンスの方が良い場合、適用の手順を、この順で置く。

## Why

**採用を増やすためのページではない。** ACD は §16.3 と README で「誰でも使ってよい」と招いているので、害の引き受け手は採用者になる（`against.md` #262）。招く以上、適用の前に読める短い英語の案内が要るが、それまで採用者の入口は `against.md` と、日本語が混じる FAQ しか無かった。B2 で我々が制御できるのは見つけてもらいやすさだけで、見つけた人に正確に伝わることもその一部である。

## How

- 版の番号を書かない。適用する版はルートの `LICENSE` が述べる（版を上げてもこの file を直さなくて済む）
- 条番号は §2〜§14 と §16.1 だけを引く（版を跨いで同じ意味）

## Constraints

- 採用を促す文を足さない。採用の捏造は失格事由である
- 別のライセンスの方が良い場合を先に書く位置を動かさない
