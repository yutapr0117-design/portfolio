# LICENSES/ACD-1.0.review-outcomes.md

## What

**OSI 側が何をしたか・何を述べたか**の記録 —— 理事会の議決とその理由、委員長の手続き運用、
**承認後にどう扱われるか**、そして**決まらない場合（留め置き）**。
§1.88 / §1.108 / §1.116 / §1.118 の 4 節。

## Why

**`ACD-1.0.review-precedents.md` が 1,002 行で Check 365 の 1,000 行上限を越えたので切り出した。**
**割る線は行数ではなく主題で選んだ** —— 残した側は「**提出そのものの読み**」
（その instrument が何を試み、リストが条文に何と言ったか）、本書は「**OSI 側の言動**」。

**`board-decisions.md` との違いは資料の種類である** —— あちらは**議事録**という一次資料からの分析、
ここは**メーリングリスト上に現れた OSI 側の言動**。**同じ決定を両方から見ることがある。**

## How

**節番号は変えていない**ので `§1.88` 等の参照は番号として解決する。
**file 名を添えていた参照 2 件は同じ commit で向け直し、mutation anchor 1 件も移動先へ付け替えた**
（「解決する」だけでは正しい対象を打っている証拠にならないため）。

## Constraints

- **分類は排他ではない。** §1.108 は「Mulan の提出の読み」でもある ——
  **境界は読み手の用途で引いてあり、論理的な分類ではない。**
- 逐語引用の出典は `rounds/` の無改変保存。**ここで引用を書き換えない。**

## Change impact

節を足すときの行き先は「**提出そのものの読みか / OSI 側の言動か**」で決める。
迷ったら `review-precedents.md` へ置き、本書からは番号で参照する。

## Audience-specific notes

- **監査人**: 各節は逐語引用と出典（`rounds/` の file 名）を持つ。
- **第三者**: **ここに在るのは他人の提出についての OSI の言動であって、ACD-1.0 への応答ではない。**
