# LICENSES/AUDIT-LEDGER-ARCHIVE.md

## What

**`LICENSES/AUDIT-LEDGER.md`（敵対的検証の台帳）から退避した、日付つきの回の記録。**
2026-09-27（506 か月の cache で初めて引用照合を回した回）・2026-09-27〜28（手で回す道具 6 本を回した回）・
2026-10-10（引用照合の 2 巡目）の 3 回分を、移す前と 1 字も変えずに収める。

## Why

本台帳は回すたびに 1 節伸びる追記型で、2026-11-01 に 898 行（advisory 900 の 2 行手前）に達した。
**BLOCKING（1,000 行）に当たってから分けるのではなく、早期警告の手前で分けた。**
古い回を退避しても、引用の分類規則（同じ行の引用前 260 字に既知の外部話者名があるか）の原典は
ここに残るので、本台帳はそこを指す。

## How

読むだけの記録である。**新しい回はここではなく `AUDIT-LEDGER.md` へ足す。**
本台帳がまた advisory に近づいたら、最も古い日付の回から順にここへ移す（節の中身は変えない）。

## Constraints

- **本文を書き換えない。** 移した時点の記述は、その日に何が分かっていたかの記録である。
  誤りが後で分かったら、本台帳の新しい回に「訂正」として書く。
- **Check 467c（発信状態の現在形）の対象外**（本台帳と同じく履歴の記録であるため）。

## Change impact

退避を足したら、本台帳の案内見出しと、この file の What の列挙を同じ PR で更新する。

## Audience-specific notes

- **監査人**: 引用照合で実際に不正確だった 8 件（09-27 の 3 件・10-10 の 4 件など）の原文と訂正の経緯はここにある。
- **次のセッション**: 新しい回の書き方の手本として読んでよいが、追記先は本台帳。
