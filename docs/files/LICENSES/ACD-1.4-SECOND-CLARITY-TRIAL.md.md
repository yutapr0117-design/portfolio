# LICENSES/ACD-1.4-SECOND-CLARITY-TRIAL.md

## What

1.4 草案の明瞭性の試作の 2 冊目。`ACD-1.4-CLARITY-TRIAL.md` の §10 以降を置く。試作文・効果の対照・先に登録した反例・
見て残したものを 1 か所に書く。

## Why

1 冊目が 900 行の advisory に届いたので、1 冊目の注記どおり節の単位で分けた。§9 までの節番号は多くの文書から
参照されているので動かしていない。

## How

規則は 1 冊目の冒頭に従う。候補と試作（25）→ 反例（bb）→ 効果を運ぶ語の比較（5a）の順に書き足し、反例が出ず効果の保存を
説明できたものだけを草案と `ACD-1.4-CHANGELIST.md` へ反映する。

## Constraints

- 凍結版（1.0〜1.3）には触れない。この file は草案を上書きしない。
- 語数の削減・CI の成功・文書の追加を、承認の見込みが上がったことと扱わない。

## Change impact

- 採用した変更は草案の冒頭の一覧と `ACD-1.4-CHANGELIST.md` の表へ移す（Check 468s が語数を照合する）。
- 1.0 に同じ文があれば errata、1.4 草案が持ち込んだものなら `ACD-1.1-SELF-AUDIT.md` へ記録する。

## Audience-specific notes

- **ai**: 新しいレンズの試作はこの file の末尾に節を足す。
- **human (新卒)**: 1 冊目の冒頭の規則から読むと、ここに並ぶ判断の理由がわかる。
- **監査人**: 「見て残したもの」の節が、直さなかった判断の記録である。
- **第三者全般**: 草案の変更の理由の一次記録で、法律家の判断ではない。
