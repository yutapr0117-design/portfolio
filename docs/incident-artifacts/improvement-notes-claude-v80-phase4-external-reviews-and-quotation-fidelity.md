# 外部レビューの扱い方と、逐語引用の忠実さ —— 2026-09-19〜20 の記録

**このセッションで最も繰り返し効いた 1 行**:
**編集はどれも英語としては良くなり、どれも証拠としては壊れる。**

## 1. 外から届いたものは、結論ではなく語彙を運ぶ

**第三者 AI レポート 3 通（09-19）から出た最大の発見は、どの結論でもなく 3 つの語だった。**

| 語 | 当てた先 | 出たもの |
| :-- | :-- | :-- |
| *crayon license* | アーカイブ 145 か月 → 15 file で実在 | **Licensing Committee 委員長の *unpredictable interpretation***（#157）——B1 を二層化した |
| *vanity license* | 同 → 10 file | **OSI の Proliferation Report の定義**と Marc Jones 氏の 4 段テスト（§1.99 / #160 / #161）|
| *contra proferentem* | 1.0 §15.3 の削除理由 | **規則の種類の取り違え**（E25 / #159）|

**手順**: 外部文書から**リストの語彙に見える語**を抜く → corpus 全体に `grep -ril` →
実在したら**発言者・日付つきで逐語**を取る → **有利・不利を同じ節に書く**。
**語が実在しないなら、それは外部の推測であってリストの語彙ではない。**

## 2. レビューが「何も見つけない」ことは、文書についての証拠ではない

**09-20 に 3 件の外部レビューが届いた**（1 回目の受け渡しでは 2 件が byte 同一で、
**「3 件ではなく 2 件だ」と書いたのは誤りだった** ——#168 で訂正済み）。

| レビュー | 指摘 |
| :-- | :-- |
| 好意的検証 | **0 件** |
| 条項適切性 | **0 件**（条ごとに「適切」）|
| **敵対的検証** | **多数。名前のある法源 8 件**（#170）|

**決定的な検定**: 3 件が読んだ草案には**ヘッダに破損があった**（`* w Section 15.5` ——#167）。
**目に見える位置に在り、どのレビューも触れていない。**

## 3. 条文内の限定は、敵対的に読む人にも見落とされる（5 件）

敵対的レビューの主張のうち**現物に当たれるもの 5 件は、すべて条文自身が答えていた**
——§1.6（法人格）/ §6.2・§6.3（他人の留保）/ §2.6+§1.4+§2.7（職務著作）/
§10 vs §12（氏名表示権）/ §4 の fallback 読み。
**最も鋭い材料をくれたレビューが、同時に 5 つの限定を見落とした。**
**これは残りを割り引く理由ではなく、#157 の読みやすさの軸の証拠である。**

## 4. 中核の構造は 4 回誤読されている

§3 / §4 / §5 の**並列**構造は、**#24 / #35（我々自身）+ 外部 2 件**で誤読された。
**外部の読み手 3 人中 2 人。** 前文が 1 段落を割いて否定している構造で、である。
→ **E28**: 否定形（*"does not depend on Section 3 being ineffective"*）をやめ、
肯定形（*"not as a fallback for it: it takes effect whether or not Section 3 does"*）へ。
**⚠ 新文言が誤読を減らす証拠は無い** ——観測はできるが、応答が効いたかは測れない。

## 5. 逐語引用の忠実さ —— 道具は在ったが、入力が空だった

`verify_dossier_quotations.py` は既定で**空の cache** を見る。

| 実行条件 | 確認できた（/322）|
| :-- | --: |
| 既定 | **100** |
| 実 corpus 145 file | 238 |
| 不足月 70 file 取得後 | 249 |
| 道具を 3 点直した後 | **269** |

**誤引用が 6 件出た**（#165 / #166）。**うち 3 件は前日の我々自身のもの。**
**型は 1 つ**: 冗長の削除・誤植の修正・綺麗な翻訳 ——**どれも英語としては良くなり、
どれも出典検索で見つからなくする。**

**道具の直し 3 点**: 残差を**自己引用**と**出典に当たれていない**に割る
（⚠ **引用記法を落としてから読む** ——落とさないと**全件が自己引用**という
一見きれいで中身の無い数を返す。実際に 1 度返した）/ **短い断片を捨てない** /
**角括弧を 2 通りに読む**（`[sic]` は落とす・`appropri[ate]` は残す）。

## 6. 決め打ちのリストは「書いた日の正しさ」しか持たない（3 件）

## 7. 「強みとしてだけ」書いていたものを直した（2 件）

- **特許報復条項の不在**（#174）——**置かれている理由**（Apache-2.0 §3 / GPLv3 §10 の抑止）が
  どこにも無かった。**真である文は「置けない」であって「置かない方が良い」ではない。**
- **「意図的に置かなかったもの」8 件**（#175）——**8 つの理由があって費用が 1 つも無かった。**
  **開示のためだけに在る面で、開示ではなく弁論をしていた。**
