# 1.4 と 1.5 草案の効果の差 —— 文脈の無い読み手の読みと仕分け

**この記録には凍結の門の印が無い。** 議題 29（2026-11-25）で、1.5 は草案のまま、出す版は 1.4 と決まった（丙 + 丁）。n8 を 7 日動かさず、一覧を固定し、まだ読んでいない 2 体に 1 回だけ読ませる（門の言い換えと 3 回目の読みはしない）。印を書くのはその読みの後で、合格のときだけである。**丁の門は議題 24 の門（HIGH 0）より緩い**（一覧に在る HIGH は 5 人の全員一致なら通る）。門を緩めたのは 2 度目で、どちらも結果を見た後である（`ACD-1.5-GATE.md`・against #332）。

## 0. 方法

1.5 草案は 1.4 を同じ効果へまとめ直したものである。errata と読みの台帳の回帰は「過去に問題になった語」しか見ないので、問題にならなかった許し・限定・念押しが落ちても出ない。そこで、**ドシエも会話も持たない読み手**（読み取り専用の agent・読んだ file は 1.4 の本文と候補の 2 本だけ）に、1.4 の条ごとに「誰かのできること・しなければならないこと・訴えられることが変わる差」を全部挙げさせた。1〜6 回目は読み手 1 体、7 回目から独立の 2 体（互いに見せない・同じ指示）。3 回目からは候補だけの敵対的な通し読みと相互参照の確認、重さ（HIGH / MEDIUM / LOW）を足し、4 回目から LOW の理由（どちらの読みでも同じ・場面が遠い）を書かせた。意図した変更は一覧で渡して除かせた。

**読み手の報告は判断ではない。** 仕分け —— 直す / 意図した変更として CHANGELIST に書く / 既に記録がある / 弱い —— は 6c が両方の文に当てて行い、LOW の理由は 59 が別に確かめた。差を (i) 1.4 から落ちた効果 と (ii) 前の束の直しが作ったもの に分けて数えた（その語がいつの固定で入ったかを見て決めた）。
