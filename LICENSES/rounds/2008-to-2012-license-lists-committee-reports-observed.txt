 > The discussion ended with some comments to the
 > effect that the issue of removing restrictions from
 > an approved license needed to be addressed.

Yes, you can see that here:
    http://crynwr.com/cgi-bin/ezmlm-cgi?17:mss:355:200809:mfknlbjbakdohplkfefg

I think Larry's advice is wise: new licenses should look to the
Jacobsen decision for wording.  In particular, I think that this
committee should ask the board to agree that if a licensor using an
open source license waives any conditions imposed by the license,
their license is automatically approved.  Not being a lawyer, I don't
know if that idea achieves the effect desired: giving a user more
freedom doesn't remove OSI approval.

Quite so.  I see no sign of that happening.  OSI, unlike FSF, has always

> I think my favorite is probably still the SIL font license, where it  
> says "The requirement for fonts to remain under this license does not  
> apply to any document created using the Font Software." As far as I can  
> tell, that allows you to convert a font to any license or no license,
