That categorisation was created for licenses submitted in languages other
than English, as it triggers a process that allows the list and board to
reasonably review the license. My understanding was that all the language
variants of EUPL were equivalent so reviewing any language is effectively
the same as reviewing all languages. Is that not the case? If not we might
need to request certified translations of all the variants...
