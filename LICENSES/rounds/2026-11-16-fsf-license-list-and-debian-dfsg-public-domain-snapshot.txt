===== (1) FSF license list, entry "CC0 1.0 Universal" (#CC0), as reported =====
1. "CC0 is a public domain dedication from Creative Commons."
2. "A work released under CC0 is dedicated to the public domain to the fullest extent permitted by law."
3. "If that is not possible for any reason, CC0 also provides a lax, permissive license as a fallback."
4. "Both public domain works and the lax license provided by CC0 are compatible with the GNU GPL."
5. "If you want to release your non-software work to the public domain, we recommend you use CC0."
6. "For works of software it is not recommended, as CC0 has a term expressly stating it does not grant you"
7. "any patent licenses."
8. "Because of this lack of patent grant, we encourage you to be careful about using software under this license;"
9. "you should first consider whether the licensor might want to sue you for patent infringement."
10. "If the developer is refusing users patent licenses, the program is in effect a trap for users"
11. "and users should avoid the program."

===== (1) FSF license list, entry "The Unlicense" (#Unlicense), as reported =====
12. "The Unlicense is a public domain dedication."
13. "A work released under the Unlicense is dedicated to the public domain to the fullest extent permitted by law,"
14. "and also comes with an additional lax license that helps cover any cases where the dedication is inadequate."
15. "Both public domain works and the lax license provided by the Unlicense are compatible with the GNU GPL."

===== (3) FSF license list, entry "Zero-clause BSD license" (#Zero-BSD), as reported (added 2026-11-16, same method) =====
25. "This license is also known as 0BSD License."
26. "Contrary to its name, it is not based on any of the BSD licenses, but on the ISC License,"
27. "with the only difference being that it doesn't contain clauses that require preservation of copyright notices"
28. "and the license notice."
29. "Accordingly, there is also no placeholder for copyright notice in the template of this license"
30. "circulating in the internet."
31. "The Zero-clause BSD License can operate as a free software license compatible with the GNU GPL,"
32. "but if the copyright notice or license notice is removed from the program,"
33. "it is not possible to safely rely on the license and users might even face liability."
34. "If you want the shortest unproblematical license, we think it is wiser to use the FreeBSD License,"
35. "as it is similarly permissive and brief."
36. "However, if you are looking for the best among lax, weak licenses,"
37. "we recommend using the Apache 2.0 license among those."
38. "The lack of requirement to preserve copyright notices and the license notice does not necessarily mean"
39. "it is safe to remove them."
40. "In some jurisdictions, removing copyright-related information may constitute copyright infringement."
41. "Additionally, if you remove copyright notices, users who receive software from you are not able to identify"
42. "who is giving them permission to use the software."
43. "If you also remove the license notice, users end up confused about whether they received a free or a nonfree program."
44. "We recommend that developers choose a license that clearly requires preserving notices for their own works"
45. "because of the confusion and antisocial effect that is the result of the 0BSD License."
46. "While there is no reason to avoid software already released under this license provided that the copyright notices"
47. "and license notice are not removed, we recommend that when using such software,"
48. "developers do not remove any copyright notices attached to it and the license notice itself."
49. "This helps to avoid the confusion and antisocial effect described above."

===== (3) FSF license list, entry "Expat No Attribution License" (#Expat0), as reported =====
50. "Some people call this license "the MIT No Attribution License," but that term is misleading,"
51. "since MIT has used many licenses for software and all of them contained requirements to preserve"
52. "copyright notices and license notice."
53. "As the license is clearly based on the Expat License, we recommend to call it the No-attribution Expat License"
54. "(but please note that Expat has never used this license)."
55. "The only difference between this license and the Expat License is that it doesn't contain clauses"
56. "that require preserving copyright notices and the license notice."
57. "Our comments about the Zero-clause BSD license apply to this license."
