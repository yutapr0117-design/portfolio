# 読みの合成 —— 未読 0 の後に、読んだ節が何を変えたか（2026-11-16）

**これは何か。** 2026-11-15〜16 に、5 人（portfolio-2f・-30・-50・-1c・-9b）で OSI の 2 つのリストの未読の会話を 0 にした（`AS-OF.md` の「未読スレッドの残り」）。読んだ結果は、各節の末尾の「**反映**:」の欄か `REFLECTION-BACKFILL.md` の表で、行き先を 1 つ以上持つ（Check 501・501b）。この文書は、その行き先を集め直して、**条文（1.4 草案）・register（B と against と errata）・入口（提出の文書）** のそれぞれに、読みが何をもたらしたかを 1 か所で見せる。オーナーの前提「未読があり、未反映のまま本申請は出せない。全て読んで反映してこそ、出せる品質になる」に、記録の側から答えるための表である。

**承認されるべき理由の側から先に言う。** 244 の読みの節を、20 年以上にわたる審査者の文に当てた結果、1.4 草案の**本文を変える必要が残った指摘は無い**。本文に向く基準（使う人の負担、著作権の拡張、サイトに依らない効力、本文の不変、特許の除外、撤回、型板の性質）は、草案が既に満たしているか、読みの途中の試作（T66・T67・T69・T72・T73）で満たした。模擬委員会で 4 人の審査者の目で通読した結果も、条を変える指摘は 4 人とも 0 件だった（`ACD-1.4-THIRD-CLARITY-TRIAL.md` の 16.1〜16.4 節）。残るのは、本文の語では閉じられない問い（B1・B10・B2）で、それは本申請の判断の材料として register に在る。

## 1. 数え方

- **対象**: `LICENSES/*.md` の `## 1.N` の節（N ≥ 45）で、比較表・変更一覧・REVISION-PROTOCOL・反映の表そのものを除く。Check 501b と同じ範囲で、244 節。
- **行き先**: 節の末尾の「**反映**:」の行。§1.242 より前で欄の無い節は、`REFLECTION-BACKFILL.md` の行の反映のセル。
- **分類**: 行き先の文に `1c` か `THIRD` があれば「条文」、`B1`〜`B15`・`against`・`errata` があれば「register」、`入口` があれば「入口」。1 つの節が複数に入る。
- **道具**: 2026-11-16 に portfolio-2f が Python で数えた（行き先の文の語で分けた）。B ごとの頻度は portfolio-9b の `count_b_topics.py` の数え方（表の「ACD への当たり方」の列も数える）に従う。

## 3. 条文 —— 51 節のうち、本文を変えたのは 4 節

| 結果 | 節の数 | 中身 |

**読み。** 読みが本文に向けたのは、ほとんどが「既に答えている」ことの確認だった。本文を変えた 4 節は、どれも決める側の文がそのまま欠陥か強すぎる語を指した場合である。

**逆側。** 「本文を変えない」が多いことは、ESA-PL の審査で Perens 氏が "meh" と評した「本文でなく説明で答える」形（`review-readings-2.md` §1.248）に見えうる。1c は、変えない判断が本文の語を引いて理由にしている形を、THIRD の 14・15 節で保っている。審査で同じ形を取るときは、答えを本文の語で示す必要がある。

**読み。** 上位の 3 つ（B10・B1・B2）は、模擬委員会の 4 人がそろって「本文の外で突く所」に挙げたものと一致する。どれも 1.4 草案の語を変えても閉じられず、B10 は効果の差を示す文書（`ACD-OSI-BOTTLENECKS-B10.md` の G1）、B1 は法律家への問い（`QUESTIONS-FOR-COUNSEL.md`）、B2 は関心の表明（`.github/ISSUE_TEMPLATE/acd-use.yml`・オーナーの線）が答えの場所である。
