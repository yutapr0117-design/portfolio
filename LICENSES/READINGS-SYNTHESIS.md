# 読みの合成 —— 未読 0 の後に、読んだ節が何を変えたか（2026-11-16）

**これは何か。** 2026-11-15〜16 に、5 人（portfolio-2f・-30・-50・-1c・-9b）で OSI の 2 つのリストの未読の会話を 0 にした（`AS-OF.md` の「未読スレッドの残り」）。読んだ結果は、各節の末尾の「**反映**:」の欄か `REFLECTION-BACKFILL.md` の表で、行き先を 1 つ以上持つ（Check 501・501b）。この文書は、その行き先を集め直して、**条文（1.4 草案）・register（B と against と errata）・入口（提出の文書）** のそれぞれに、読みが何をもたらしたかを 1 か所で見せる。オーナーの前提「未読があり、未反映のまま本申請は出せない。全て読んで反映してこそ、出せる品質になる」に、記録の側から答えるための表である。

**承認されるべき理由の側から先に言う。** 244 の読みの節を、20 年以上にわたる審査者の文に当てた結果、1.4 草案の**本文を変える必要が残った指摘は無い**。本文に向く基準（使う人の負担、著作権の拡張、サイトに依らない効力、本文の不変、特許の除外、撤回、型板の性質）は、草案が既に満たしているか、読みの途中の試作（読みが起点の T67・T69・T72（T73 はその再改）と、読みが支えた T64・T66・T71）で満たした。模擬委員会で 4 人の審査者の目で通読した結果も、条を変える指摘は 4 人とも 0 件だった（`ACD-1.4-THIRD-CLARITY-TRIAL.md` の 16.1〜16.4 節）。**ただし集め方は揃っていない**: Chestek 氏（16.2）・Fontana 氏（16.3）・Perens 氏（16.4）の 3 人はアーカイブの未引用の通まで当て、Villa 氏（16.1）はドシエに在る文から当てた。ドシエに在る文だけで当てると、ドシエが扱った基準しか出てこないので、その 0 件は作りからして当然に近い（portfolio-30 の当て直しの指摘）。残るのは、本文の語では閉じられない問い（B1・B10・B2）で、それは本申請の判断の材料として register に在る。

## 1. 数え方

- **対象**: `LICENSES/*.md` の `## 1.N` の節（N ≥ 45）で、比較表・変更一覧・REVISION-PROTOCOL・反映の表そのものを除く。Check 501b と同じ範囲で、244 節。
- **行き先**: 節の末尾の「**反映**:」の行。§1.242 より前で欄の無い節は、`REFLECTION-BACKFILL.md` の行の反映のセル。
- **分類**: 行き先の文に `1c` か `THIRD` があれば「条文」、`B1`〜`B15`・`against`・`errata` があれば「register」、`入口` があれば「入口」。1 つの節が複数に入る。
- **道具**: 2026-11-16 に portfolio-2f が Python で数えた（行き先の文の語で分けた）。B ごとの頻度は portfolio-9b の `count_b_topics.py` の数え方（表の「ACD への当たり方」の列も数える）に従う。同じ日に 9b が `count_b_topics.py --destinations`（B × 行き先）を足し、同じ main で条文 52・register 201・入口 108・なし 5 を返した。行き先の語の拾い方の差で、条文と入口が 1 節ずつ多い。**確定の日には、この文書の数を `--destinations` の出力で書き直す**（数え方を 1 つの道具に寄せるため）。
