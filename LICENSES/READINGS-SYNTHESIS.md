# 読みの合成 —— 未読 0 の後に、読んだ節が何を変えたか（2026-11-16）

**これは何か。** 2026-11-15〜16 に、5 人（portfolio-2f・-30・-50・-1c・-9b）で OSI の 2 つのリストの未読の会話を 0 にした（`AS-OF.md` の「未読スレッドの残り」）。読んだ結果は、各節の末尾の「**反映**:」の欄か `REFLECTION-BACKFILL.md` の表で、行き先を 1 つ以上持つ（Check 501・501b）。この文書は、その行き先を集め直して、**条文（1.4 草案）・register（B と against と errata）・入口（提出の文書）** のそれぞれに、読みが何をもたらしたかを 1 か所で見せる。オーナーの前提「未読があり、未反映のまま本申請は出せない。全て読んで反映してこそ、出せる品質になる」に、記録の側から答えるための表である。

**承認されるべき理由の側から先に言う。** 255 の読みの節を、20 年以上にわたる審査者の文に当てた結果、1.4 草案の**本文を変える必要が残った指摘は無い**。本文に向く基準（使う人の負担、著作権の拡張、サイトに依らない効力、本文の不変、特許の除外、撤回、型板の性質）は、草案が既に満たしているか、読みの途中の試作（読みが起点の T67・T69・T72（T73 はその再改）・T82 と、読みが支えた T64・T66・T71）で満たした。模擬委員会で 5 人の審査者の目で通読した結果も、条を変える指摘は 5 人とも 0 件だった（`ACD-1.4-THIRD-CLARITY-TRIAL.md` の 16.1〜16.5 節）。5 人ともアーカイブの、ドシエが引いていない通まで当てた。Villa 氏（16.1）は最初ドシエに在る文だけから当てていた —— それではドシエが扱った基準しか出てこないので、0 件は作りからして当然に近い（portfolio-30 の指摘）。2026-11-16 にアーカイブの同氏の通 331 通から論点の語に当たる 62 通を読んで補い、0 件のままだった。残るのは、本文の語では閉じられない問い（B1・B10・B2）で、それは本申請の判断の材料として register に在る。

**読み。** 上位の 3 つ（B10・B1・B2）は、模擬委員会の 4 人がそろって「本文の外で突く所」に挙げたものと一致する。どれも 1.4 草案の語を変えても閉じられず、B10 は効果の差を示す文書（`ACD-OSI-BOTTLENECKS-B10.md` の G1）、B1 は法律家への問い（`QUESTIONS-FOR-COUNSEL.md`）、B2 は関心の表明（`.github/ISSUE_TEMPLATE/acd-use.yml`・オーナーの線）が答えの場所である。
